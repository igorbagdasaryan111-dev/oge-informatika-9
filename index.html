01 / Короткий конспект

Как считать пути

Что показывает схема

Стрелка обозначает дорогу и направление движения. В обратную сторону по ней ехать нельзя.

Число у пункта — это количество разных способов добраться до него из начала, а не расстояние.

Алгоритм решения

1

Поставь 1 у начального пункта: в нём уже находится один путь.

2

Двигайся по стрелкам. Для каждого пункта сложи числа всех пунктов, откуда в него входят стрелки.

3

Число у конечного пункта — ответ. Проверяй направление каждой стрелки.

03 / Пример решения

Считаем по стрелкам

Даны дороги A → B, A → C, B → C и C → D. Сколько путей из A в D?

В A ставим 1; в B приходит один путь, значит B = 1.

В C стрелки идут из A и B: 1 + 1 = 2. В D стрелка идёт только из C, поэтому D = 2.

Это пути A → C → D и A → B → C → D.
